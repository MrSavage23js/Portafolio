Caso 01 / 04

Sistema de tickets de soporte interno

En desarrollo
Problema
Las solicitudes de soporte llegaban sin folio, prioridad ni seguimiento centralizado.
Solución
Aplicación web donde cada solicitud recibe un folio único por departamento y año, se clasifica por nivel de urgencia con código de color y dispara notificaciones por correo (SMTP). Los administradores cuentan con un dashboard para dar seguimiento.
Stack
React · TypeScript · Vite · Node.js · Express · PostgreSQL · Kysely · Nodemailer (SMTP)
Mi rol
Diseño y desarrollo full stack: modelo de datos, API, interfaz web y notificaciones por correo.

Caso 03 / 04

App web de control de producción

Completado
Problema
El control de pesos de producción se llevaba en un archivo de Excel, lo que complicaba la captura simultánea y la consistencia de los datos.
Solución
Aplicación web que digitaliza el control de pesos y reemplaza el Excel: varios usuarios capturan al mismo tiempo y la información se puede exportar a Excel cuando se necesita.
Stack
HTML · CSS · JavaScript · Firebase (Firestore) · ExcelJS
Mi rol
Desarrollo completo: interfaz de captura, sincronización en tiempo real y exportación a Excel.
Resultado
El control de pesos ya no depende de un archivo de Excel: las capturas se sincronizan en tiempo real entre el equipo y se exportan a Excel cuando se necesitan.

Caso 04 / 04

Procesador de reportes de ventas

Completado
Problema
Revisar los reportes de ventas requería trabajo manual para obtener la información relevante.
Solución
Herramienta web: el usuario sube el reporte, el sistema lo procesa, lo cruza con el catálogo de productos y muestra la información.
Stack
React · TypeScript · Vite · Cloudflare Workers · Cloudflare D1 (SQL) · SheetJS / ExcelJS
Mi rol
Desarrollo completo: carga y procesamiento de reportes, base de datos e interfaz web.
Resultado
El cruce entre los reportes de ventas y el catálogo de productos se hace de forma automática dentro de la herramienta.
